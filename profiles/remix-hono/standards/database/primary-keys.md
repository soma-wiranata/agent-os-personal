# Primary Keys

All new tables must use string-based IDs generated by `cuid2` via Drizzle's `$defaultFn`.

```typescript
import { createId } from '@paralleldrive/cuid2'

export const myTable = pgTable('my_table', {
  id: text('id').$defaultFn(() => createId()).primaryKey(),
})
```

- `cuid2` generates collision-resistant, URL-safe IDs application-side — no waiting for DB insertion
- **Never use:** `serial()`, `uuid()`, or `crypto.randomUUID()` as primary keys unless integrating with a strict legacy schema
